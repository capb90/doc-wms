# Anexo F9 — Matriz observada del API (2026-10-03)

Sondeo de **345 operaciones** del swagger (se excluyen `auth/*` y `administration/backups/run`) con las 9 cuentas y sin token: 3.450 peticiones. Los parámetros de ruta usan un GUID inexistente y las escrituras llevan un cuerpo JSON incompleto, así que la petición pasa la autorización pero no ejecuta la acción. **Acceso = la respuesta no es 401/403** (200, 400, 404, 409, 415 o 500). Las 4 importaciones multipart se repitieron con un archivo, porque el 415 por tipo de contenido ocurre antes de la autorización. Datos crudos: `muestras-f9/f9-api-matriz.json`.

Las cuentas multirol (`v_montenegro` Admin+Billing, `j_coral` Billing+FT, `f_chosi` Scale+FT) recibieron **exactamente la unión** de sus roles en todas las operaciones.
