# DEF-F6-010 — El comprobante del pago no se puede guardar (varchar(500))

| Campo | Valor |

| Estado | Verificado |

## Pasos para reproducir
Registrar un pago con `voucherUrl` = data-URL de una imagen de 70 KB.

## Resultado esperado
Se guarda el comprobante.

## Resultado obtenido
409 «22001: value too long for type character varying(500)».

## Impacto
No se puede adjuntar soporte de pago.

## Pista técnica
`PaymentDialog.vue:64` envía base64; guardar el archivo y su URL.
