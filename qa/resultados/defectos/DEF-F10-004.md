## Pasos para reproducir
Detener el API y navegar a `/billing/invoices`.

## Resultado esperado
Un solo aviso claro («Sin conexión con el servidor»), sin código HTTP inventado; al volver el API, la pantalla se recupera.

## Resultado obtenido
12 avisos idénticos «Error 500 / Error de conexión con el servidor» cubren la página (no hubo respuesta 500: fue rechazo de conexión). Al volver el API la lista no se actualiza sola; hay que navegar (la sesión se conserva).

## Impacto
Pantalla ilegible durante una caída; el «500» confunde al soporte.

## Pista técnica
Agrupar errores de red (un aviso por tipo o un banner de conexión), no rotularlos con status 500, y reintentar o invalidar las consultas al reconectar.
