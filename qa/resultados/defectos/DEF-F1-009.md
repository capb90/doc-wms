# DEF-F1-009 — Usuario desactivado, con rol retirado o deslogueado conserva acceso con su token hasta que expira

| Ambiente y commits | Local · FE `a5289ce` · BE `191d4b1` |
| Estado | Verificado |

## Pasos para reproducir
1. Iniciar sesión con `qa_inactivo` (rol Bodega).
2. Desde Admin, desactivarlo.
3. Con el token del paso 1, llamar `GET user/me` y `GET warehouse/locations`.
4. Repetir quitando un rol en lugar de desactivar, y tras hacer logout.

## Resultado esperado
El acceso se corta al desactivar, retirar el rol o cerrar sesión (o en pocos minutos).

## Resultado obtenido
Las llamadas siguen respondiendo 200 hasta que expira el access token (60 min en esta configuración). El refresh sí se rechaza.

## Impacto
Un usuario despedido o con permisos retirados puede seguir operando hasta una hora.

## Pista técnica
Autenticación JWT sin estado; `user/me` no revisa `IsActive`. Opciones: comprobar `SecurityStamp`/`IsActive` en cada petición o acortar la vida del token.
