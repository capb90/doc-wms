## Precondiciones y datos

Ninguno. Sonda de autorización de la ronda: 348 operaciones del swagger con las 8 cuentas `qa.pre.*` y sin token (`evidencias/PRE/pre-api-matriz.json`).

## Pasos para reproducir

1. Con Admin: `POST /api/v1/warehouse/locations` con el cuerpo `{}`.

## Resultado esperado

400 con el mensaje del validador en español («El código es requerido.» u otro), como el resto de los catálogos.

## Resultado obtenido

`500 Error del servidor`: «[InvalidOperationException] An exception was thrown while attempting to evaluate a LINQ query parameter expression. See the inner exception for more information. To show additional information call 'DbContextOptionsBuilder.EnableSensitiveDataLogging'.». Es la única operación de las 348 que responde 5xx en la sonda.

## Evidencia

- `curl` con `qa.pre.admin` → 500 y el cuerpo citado.
- `evidencias/PRE/pre-api-matriz.json`: `"POST warehouse/locations": {"admin": 500, …}`; en `muestras-f9/f9-api-matriz.json` (2026-10-03) ya respondía 500 a `capb90` y `v_montenegro`.

## Impacto

Solo por API con datos incompletos: la pantalla exige el código. Expone un texto técnico en inglés. Sin efecto en datos.

## Pista técnica (opcional)

El validador de la creación consulta la base con el código nulo antes de validar que venga.

## Corrección (2026-10-25, plan `planes/plan-cerrado-correccion-def-f11-029-033-2026-10-25.md`, sin commit)

- Nuevo `CreateWarehouseLocationValidator` (D4 del plan): código y nombre requeridos, capacidad mayor que cero, y los largos de la columna (código 50, nombre 200; pasillo, rack y nivel 50), con los mensajes del dominio. El handler ya no llama `Trim()` sobre un código nulo.
- `Wms.Tests/Warehouse/CreateWarehouseLocationValidatorTests` y `Wms.IntegrationTests/Warehouse/CreateLocationValidationTests` (cuerpo `{}` → 400 con «El código de ubicación es requerido.»; cuerpo válido → 201).
- **Re-test local (PRE-B6-03):** `POST warehouse/locations` con `{}` como Admin → **400** «Error de validación.» con «El código de ubicación es requerido.», «El nombre de ubicación es requerido.» y «La capacidad debe ser mayor a cero.». Evidencia: `evidencias/PRE/pre-retest-def-f11-029-033.txt`.
