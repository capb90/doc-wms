# DEF-F1-007 — Editar con identificación o SKU duplicados muestra el error crudo de Postgres; el nombre de producto se puede duplicar

## Pasos para reproducir
1. Editar `QA Importador` y ponerle el NIT de `QA Cliente Uno`.
2. Editar `QA Aceite` con el SKU de `QA Repuestos`.
3. Editar `QA Aceite` con el nombre «QA Cebolla».

## Resultado esperado
Mensajes de negocio legibles («Ya existe un tercero/producto con…») y nombre de producto único también al editar.

## Resultado obtenido
1 y 2: 409 «23505: duplicate key value violates unique constraint "idx_stakeholder_identification" / "idx_product_sku" … Detail redacted…». 3: se acepta (dos productos «QA Cebolla»); se restauró.

## Impacto
Mensajes técnicos al operario; productos homónimos en los selectores de báscula.

## Pista técnica
`UpdateStakeholderHandler` y la edición de producto no revisan unicidad; `GlobalExceptionHandler.cs:103` devuelve el texto de la base.
