# DEF-F4-005 — La recepción directa crea ingresos abiertos duplicados para el mismo vehículo

## Pasos para reproducir
1. QAB204 tiene un ingreso «Solo bodega» abierto.
2. Registrar dos recepciones directas por API para QAB204.
3. `GET entry-logs?HasDeparture=false&LicensePlate=QAB204`.

## Resultado esperado
Un solo ingreso abierto por vehículo (regla F2-ING-004); la recepción usa el existente.

## Resultado obtenido
QAB204 queda con 3 ingresos abiertos; el original sigue en los pendientes directos.

## Impacto
Rompe la regla de un ingreso abierto, la salida en Vigilancia y la trazabilidad del camión.

## Pista técnica
`CreateReceptionWithoutWeighbridgeCommandHandler.cs:169-178` crea un `EntryLog` sin buscar el abierto.
