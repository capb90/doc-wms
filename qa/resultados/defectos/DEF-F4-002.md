# DEF-F4-002 — La recepción directa sin báscula falla siempre desde la interfaz (500)

| Campo | Valor |
|---|---|
| Severidad | CRITICAL |
| Módulo | Bodega |

| Riesgo del plan | R-BOD-01 ★ |

| Ambiente y commits | Local · FE `41c19cd` · BE `191d4b1` |
| Estado | Verificado |

## Pasos para reproducir
1. Bodega → Recepción → Recepción directa → «Recibir» en `QAB204` («Solo bodega»).
2. Completar conductor, vehículo, cliente, producto, cantidad, ubicación, firma y motivo.
3. «Completar Recepción Manual».

## Resultado esperado
Recepción completa, depósito INSP nuevo en Borrador con el stock declarado.

## Resultado obtenido
`POST warehouse/receptions/without-weighbridge` → 500 «[ArgumentNullException] Value cannot be null. (Parameter 'request')»; toast «No se pudo registrar la recepción». Por API, con `receptionProducts` y un `authorizedByUserId` válido, responde 201 (2026INSP00002 y 2026INSP00003). Con `authorizedByUserId: ""` responde 500.

## Impacto
El ingreso «Solo bodega» no se puede recibir desde la interfaz; además, un dato vacío del cliente produce 500 en vez de 400.

## Pista técnica
`ReceptionStepManualInfo.vue:196-237` envía campos sueltos y `authorizedByUserId: ""`; el backend no valida el GUID vacío antes de usarlo.
