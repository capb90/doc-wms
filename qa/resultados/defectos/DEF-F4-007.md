## Pasos para reproducir
1. `/warehouse/receptions/history` → Fecha desde = Fecha hasta = hoy → Aplicar.
2. Por API: `FromDate=2026-10-02T00:00:00-05:00` o `FromDate=2026-10-02`.

## Resultado esperado
Las recepciones de ese día; el API acepta la fecha o responde 400.

## Resultado obtenido
0 resultados: «hasta» se envía como la medianoche del día (`toISOString()` de la fecha del DatePicker). El API responde 500 «Cannot write DateTimeOffset with Offset=-05:00:00…» con offset, y 500 con fecha sin hora.

## Impacto
El filtro de fechas no sirve para el caso habitual («hoy»). El historial de montacargas usa el mismo patrón.

## Pista técnica
`ReceptionList.vue:56-57` (fin de día) y normalizar a UTC en el backend.
