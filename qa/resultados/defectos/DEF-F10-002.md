# DEF-F10-002 — El formulario de pago borra el monto y la referencia cuando el backend rechaza el pago

| Severidad | MINOR |
| Módulo | Facturación |

| Estado | Verificado |

## Pasos para reproducir
1. QAE-SIIGO-001 → «Agregar Pago»: monto 1.000, referencia QAF10-COMPROBANTE, comprobante PNG de 70 KB.
2. «Registrar Pago».

## Resultado esperado
Mensaje claro y el formulario conserva lo digitado para corregir y reintentar.

## Resultado obtenido
El backend responde 409 (DEF-F6-010) y el diálogo queda abierto con **monto $ 0 y referencia vacía**; solo conserva el archivo. Los avisos muestran el texto crudo «22001: value too long for type character varying(500)» dos veces.

## Impacto
El operario debe volver a digitar el pago; el mensaje no le dice qué hacer.

## Pista técnica
`PaymentDialog.vue:78-81` llama `resetForm()` antes de conocer el resultado; resetear solo al éxito (onSuccess).
